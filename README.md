
# Portfolio Analytics Toolkit

A reusable Python toolkit that ingests holdings/transactions/prices and produces performance, risk, attribution, a simple 60/40 vs Tilted backtest, and a Monte Carlo retirement projection. Exports PNG charts and an `output/report.html` you can paste into Canva/PowerPoint.

## Quickstart

```bash
pip install -r requirements.txt
python run_pipeline.py
# open output/report.html
```
